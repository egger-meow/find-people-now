# 街街貓素材整合

街街貓是品牌敘事角色；操作仍以文字、狀態和按鈕為主。主要頁面只在登入或真正的空狀態、等待狀態放一張插圖，避免每張活動卡都出現吉祥物。插圖以 `BoxFit.contain` 保持去背邊緣和完整輪廓，並提供語意描述。

| 原始素材 | 視覺內容與判斷 | 位置 |
| --- | --- | --- |
| `login_screen.png` | 全身街街貓與活動小圖示，適合第一次認識品牌；比例較高，限制高度以保留信箱及驗證碼操作。 | 登入頁，已使用 |
| `目前還沒有人在揪，但你可以當第一個.png` | 拿放大鏡尋找活動，語意和真空狀態吻合。 | 首頁校園動態空狀態及「我的活動」進行中空狀態，已使用 |
| `系統正在幫你找也想做同一件事的人.png` | 看手機及候選夥伴連線，只有配對進行時才準確。 | 等待室 REQUESTING，已使用 |
| `配對成功.png` | 成團慶祝，不能拿來表示候選人或待確認。 | 等待室 MATCHED 過渡狀態，已使用 |
| `大家一起投票決定去哪裡.png` | 地圖與多個勾選地點，適合地點投票的說明；實際投票表單需要保留候選及票數的優先層級。 | 使用說明第 4 步的主題由教學圖承接；暫不加入投票操作卡 |
| `我到了.png` | 手機與集合點定位，適合報到說明；報到按鈕有不可撤回的確認步驟，不能讓插圖擠壓提醒。 | 使用說明第 5 步的主題由教學圖承接；暫不加入報到操作卡 |
| `下次再揪.png` | 與夥伴再次相約，適合活動結束後的說明；再約需要雙方表態。 | 使用說明第 6 步的主題由教學圖承接；暫不加入決策按鈕旁 |
| `tutorial_steps/1.png` 至 `6.png` | 六張連續圖，依次是選活動、等待找人、安全確認、集合地點、群組互動與再約；一張一節比首次登入灌入整套流程更合適。 | 常駐使用說明，已使用 |
| `in-app banner.png` | 有完整校園背景和留白，適合寬幅宣傳；首頁目前以校區、時間篩選及活動卡作首屏資訊。 | 暫不加入，以免首屏擠壓核心決策 |
| `icon.png` | 圓角品牌頭像，適合啟動畫面或正式 app icon。平台圖示需要各尺寸及安全區校驗。 | 保留供專項圖示更新 |
| `stickers/06_sneaky_drool.png` | 上方有星星、略顯困惑的街街貓；輕鬆但不會暗示操作成功。 | 共用使用者錯誤狀態，已使用；搭配友善訊息及可用時的重試按鈕 |
| `stickers.png`、其餘 `stickers/01` 至 `18` | 十八種表情、運動、讀書、飲食、奔跑、迷路及朋友合照；情緒貼圖適合交流，但目前沒有貼圖訊息介面。 | 不加入功能按鈕或通知清單，避免把情緒插圖誤當狀態或行動 |

原始檔保留於根目錄 `images/`；Flutter 只打包使用到的副本。若將來加入貼圖傳送或專門的報到完成畫面，再從對應原圖挑選，避免全套素材被打包並重複出現在每個頁面。
