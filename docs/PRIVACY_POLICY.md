## 一、我們收集哪些資料

### 1.1 註冊時收集
- **學校信箱**：僅接受 `@nycu.edu.tw`、`@nthu.edu.tw` 兩校網域，用於驗證你是本校學生，並自動判定你屬於哪所學校（你無法自行選擇學校）
- **頭像照片**：註冊時必填，用於配對後讓對方辨識你
- **顯示名稱**
- **學制**（大學部／碩士班／博士班）：註冊時必填
- **至少一項聯絡方式**（Instagram、LINE 或 Discord 帳號擇一以上）：用於配對成立後與其他使用者交換聯繫方式

### 1.2 選填資料
- 性別（僅供個人資料展示，**不會**用於配對邏輯或篩選對象）
- 自我介紹
- 科系

### 1.3 使用過程中產生的資料
- 你建立、加入、參與的活動配對紀錄（時間、地點範圍、活動類型、人數）
- 出席/ 取消 / 未出席的紀錄（用於計算你的「可信度」等級，顯示為 Trusted／Normal／New 三級，**不會**顯示為精確分數或百分比）
- 集合地點與見面提示等你主動填寫的文字內容
- 完成活動後的回報內容（活動是否順利進行）
- 系統通知紀錄

## 二、我們如何使用你的資料

| 資料 | 用途 |
|---|---|
| 學校信箱 | 驗證身份、判定所屬學校、寄送一次性驗證碼 |
| 頭像、顯示名稱、學制、科系、自我介紹 | 配對成立後展示給活動成員，幫助彼此辨識、降低陌生感 |
| 性別 | **僅供展示，不用於任何配對篩選邏輯** |
| 聯絡方式（IG／LINE／Discord） | 配對成立後顯示給同一場活動的其他成員，供你們自行聯繫；**平台本身不提供站內聊天功能** |
| 出席／取消紀錄 | 計算你的可信度等級，作為部分低人數活動的准入門檻依據 |
| 活動配對紀錄 | 執行配對演算法、避免短期內重複配對到同一對象 |

我們**不會**將你的個人資料用於：
- 廣告投放或行銷用途
- 出售或提供給與活動媒合無關的第三方
- 依性別進行配對篩選（這是本產品刻意的設計原則，見常見問答）

## 三、資料保留期限

我們只在資料真正有用時保留它，並且有明確的自動失效機制：

| 資料類型 | 保留規則 |
|---|---|
| 配對成立後的聯絡方式顯示 | 活動成立起 24 小時後自動從 App 內隱藏，除非雙方互按「再約」才永久保留 |
| 配對未成立的紀錄（避免短期重複配對到同一人） | 7 天後自動失效，非永久記錄 |
| 帳號停權（連續多次未出席） | 7 天後自動解除，非永久 |
| 你的活動紀錄、可信度計算依據 | 保留期間帳號存續期間內滾動計算（近 30 天），供你查閱與計算可信度等級之用 |

## 四、我們使用的第三方服務

本 App 使用 **Supabase** 作為後端資料庫與身份驗證服務供應商。你的帳號資料、活動紀錄等會儲存在 Supabase 提供的雲端基礎設施上。Supabase 作為我們的資料處理者，依其自身的隱私權政策與資安措施運作，你可以在 〔Supabase 官方隱私權政策連結〕 了解更多。

我們**不會**使用第三方廣告或追蹤服務。

## 五、你的權利

你可以：
- **檢視、修改**你的個人資料（顯示名稱、頭像、聯絡方式、自我介紹、科系等）
- **在 App 內自行刪除帳號**（設定 → 刪除帳號），不需要聯絡客服或等待人工處理。刪除是立即生效、不可復原的：
  - **會立刻清空、無法復原的識別資料**：信箱、顯示名稱、頭像、性別、自我介紹、科系、所有聯絡方式（IG／LINE／Discord）
  - **會立刻整批刪除的資料**：你自己的系統通知記錄；系統內部用來避免短期內重複配對到同一人的暫存紀錄（這類紀錄本來就與你無關的其他使用者無關，刪除後也不會再有作用）
  - **仍會被其他使用者間接看到、但已去識別化的資料**：如果你曾經與其他使用者共同完成活動配對、投票選過集合地點、留下集合提示或完成回報，這些紀錄本身會保留（不是為了保留你的資料，而是因為刪掉會讓「跟你同組過的其他使用者」自己的出席統計、得票數、集合資訊出現錯誤或缺漏）。保留的紀錄不會再連結到任何可以識別你的欄位——你的顯示名稱、頭像等識別資訊已經被清空，其他人只會看到一個顯示為「已刪除的使用者」的空殼帳號
  - **仍在進行中的配對／活動**：若你刪除帳號時名下還有尚未成局的配對邀請，該邀請會直接結束，不會留給其他人繼續等待；若你只是別人邀請裡的成員，則視同你自行退出，不影響邀請本身或其他成員
  - **帳號本身**：刪除後你無法再用同一組學校信箱登入；若同一個信箱地址想再次使用本服務，需要重新註冊，會產生一個全新、與先前紀錄無關的帳號
  - 你目前登入中的裝置，在你點下刪除的當下即無法再對系統做任何操作；但受限於登入機制本身的技術限制，裝置上短暫快取的登入憑證要到自然到期（通常在數十分鐘內）才會完全失效——這段期間內帳號的個人資料已經清空，不影響上述保護效果

## 六、常見問答

**Q：為什麼沒有性別篩選功能？**
A：本產品的核心理念是「找一起做事的人，不是找對象」。我們刻意不讓性別成為配對條件，避免產品滑向交友導向。你的性別資訊僅用於個人資料展示。

**Q：我可以看到跟我配對的人的哪些資訊？**
A：配對成立前，系統採「盲配」機制，你不會看到候選對象的個人資料；配對成立後，才會顯示對方的頭像、顯示名稱、學制、科系（如有填寫）與可信度等級。

**Q：平台會不會看我跟其他使用者的私訊內容？**
A：不會，本 App 不提供站內聊天功能，配對成立後你們透過自己選擇的外部軟體（IG／LINE／Discord）聯繫，內容不會經過我們的伺服器。
