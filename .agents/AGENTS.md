# Project & System Rules

## Commit Convention & Workflow
- When committing and pushing changes, always follow Conventional Commit format (`feat: ...`, `docs: ...`, `refactor: ...`, `fix: ...`, `chore: ...`, etc.).
- Always commit and push after completing each part / logical unit of work.

## Skill Usage Guidelines

### 1. Conservative Superpowers Usage
- Skills in `superpowers` should be used conservatively to avoid wasting tokens and making excessive calls. Only invoke them when necessary.

### 2. Frontend & UI/UX Design
- When designing or implementing frontend UIs, utilize skills like `ui-ux-pro-max` to ensure top-quality UI/UX design, visual aesthetics, color schemes, and responsive layouts.

### 3. Marketing & Copywriting (文案)
- When writing marketing copy, hero sections, product messaging, or promotional content, utilize specialized marketing skills (such as `copywriting`, `marketing-skills`, `product-marketing`, etc.).
